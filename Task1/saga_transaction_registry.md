# Task1 — Реестр транзакций

| Транзакция          | Описание                                                                                                 |            Тип | Компенсация          |
|---------------------|----------------------------------------------------------------------------------------------------------|---------------:|----------------------|
| CREATE_PAYMENT      | Пользователь формирует заказ и инициирует платёж (создаётся запись транзакции).                          |    повторяемая | NONE                 |
| RESERVE_MONEY       | Блокировка средств на счёте плательщика                                                                  | компенсируемая | RELEASE_RESERVATION  |
| CHARGE_MONEY        | Списание средств со счёта плательщика                                                                    | компенсируемая | REFUND_CHARGE        |
| FRAUD_CHECK         | Вызов внутреннего FraudCheck Service и внешних провайдеров — может вернуть {ALLOW, DENY, MANUAL_REVIEW}. |    повторяемая | NONE                 |
| AWAIT_MANUAL_REVIEW | Ожидание решения оператора (таймаут 20 минут). Транзакция переводится в состояние ожидания.              |    повторяемая | CANCEL_MANUAL_REVIEW |
| TRANSFER_MONEY      | Перевод денег контрагенту                                                                                |    необратимая | NONE                 |
| UPDATE_ACCOUNTING   | Обновление бухгалтерских и финансовых систем                                                             |    повторяемая | REVERT_ACCOUNTING    |
| NOTIFY_CLIENT       | Отправка уведомления клиенту о статусе операции                                                          |    повторяемая | NONE                 |
| ALERT_SECURITY      | Пометка операции как подозрительной и уведомление команды безопасности для дальнейшего анализа.          |    повторяемая | NONE                 |
| FINALIZE_SAGA       | Финальное завершение состояния (COMPLETED / FAILED).                                                     |    повторяемая | NONE                 |
